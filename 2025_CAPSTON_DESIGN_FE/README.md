## 🗂 프로젝트별 상세

### 💊 MediCheck — 약 복용 관리 앱
> `take-medicine-page` / `take-medicine-progress` / `software_team_my-page`

약을 구매해두고 잊거나, 성분 정보를 알고 싶은 사용자를 위한 약 복용 관리 앱.  
약 검색·상세 조회·복용 알림·마이페이지·진행 상태 추적 기능을 포함합니다.

- **기여:** 프론트엔드 대부분의 화면 직접 구현 + 기존 디자인 전면 수정 (기여율 약 80~85%)
- **수상:** 소프트웨어공학 팀 프로젝트 반영 비율 60%, **A 학점**
- **상세:** [`MediCheck README`](./take-medicine-page/README.md) 참고

---

### 📖 치매 노인을 위한 학습지 UI — React 수업 팀 프로젝트
> `teamproject-react-class`

교수님이 제공한 치매 노인용 학습지 디자인 시안을 React로 구현한 팀 프로젝트.  
본인 담당 페이지 구현(`src/Page48~Login`) 외에도 팀원 코드 취합 및 배포까지 맡았습니다.

- **역할:** FE 리더 — 본인 페이지 구현 + 팀 코드 통합 + 배포 담당
- **비고:** 과제 제출 후 배포 링크 만료
- **상세:** [`학습지 UI README`](./teamproject-react-class/README.md) 참고

---

### 🤖 패션 이미지 분류 딥러닝 모델
> `express-test`

Fashion MNIST 이미지셋을 학습시켜 옷 종류를 분류하는 딥러닝 개인 프로젝트.  
AI 개념이 없는 상태에서 Jupyter Notebook과 TensorFlow를 처음 다루며 완성했습니다.

- **역할:** 개인 프로젝트 (전체 구현)
- **상세:** [`딥러닝 프로젝트 README`](./express-test/README.md) 참고

---

### 🐻‍❄️ EcoPolar — 에코 활동 기반 환경 보호 앱
> `2025_CAPSTON_DESIGN_FE`

텀블러 사용·대중교통 이용 등 일상의 에코 활동을 인증하면 북극곰 캐릭터가 성장하는 게이미피케이션 환경 보호 앱.  
기획·UI/UX 설계·프론트엔드 개발까지 팀장으로서 직접 전담했습니다.

- **역할:** FE 팀장 — 기획, UI/UX 디자인, 프론트엔드 개발 (에코 활동 인증 페이지 제외 전담)
- **상세:** [`EcoPolar README`](./2025_CAPSTON_DESIGN_FE/README.md) 참고
