
# 🐻‍❄️ EcoBear — 에코 활동 기반 환경 보호 앱

> 2025 졸업 캡스톤 디자인 프로젝트 | FE 팀장  
> 기획 · UI/UX 설계 · 프론트엔드 개발 전담

<br>

## 🔍 왜 만들었나요?

기후변화와 지구온난화에 대한 인식은 높아졌지만, 정작 개인의 행동으로 이어지지 않는 경우가 많습니다.

> _"나 혼자 텀블러 쓴다고 뭐가 달라지겠어?"_

이 생각의 근본적인 원인은 **내 작은 행동이 실제로 어떤 변화를 만드는지 체감되지 않는다는 것**입니다.

**EcoBear**는 그 체감을 만들기 위해 기획한 앱입니다.

텀블러 사용, 대중교통·자전거 이용 같은 일상의 에코 활동을 인증하면,  
북극곰 캐릭터와 빙하가 실제로 회복되는 모습을 시각적으로 보여줍니다.  
내 행동이 환경에 어떤 변화를 일으키는지 **게이미피케이션으로 직접 느낄 수 있는 환경 보호 앱**입니다.

<br>

## 🎯 핵심 컨셉 — 게이미피케이션

| 에코 활동 누적 | 변화 |
|---|---|
| 활동 인증 → 빙하 조각 수집 | 점점 녹아가던 빙하가 복구되기 시작 |
| 빙하 일정량 달성 | 북극곰 표정이 😢 → 😊 으로 변화 |
| 더 많은 활동 누적 | 북극곰 가족이 생기고, 먹이를 줄 수 있게 됨 |

> 북극곰 캐릭터는 팀이 직접 디자인했으며,  
> 애니메이션 구현의 한계로 Gemini AI의 도움을 받아 이미지 형태로 제작해 적용했습니다.

<br>

## 🙋 내가 맡은 역할 — FE 팀장 (기획부터 개발까지 전담)

이 프로젝트에서 저는 백엔드 팀원 없이 **기획·아이디어·UI/UX 설계·프론트엔드 개발**을 거의 전부 맡았습니다.

- **기획 및 아이디어:** 서비스 컨셉, 게이미피케이션 구조 설계
- **UI/UX 디자인 (Figma):** 사용자 인증 페이지 제외 전체 화면 설계
- **프론트엔드 개발:** 에코 활동 인증 페이지 제외 전체 화면 구현
- **팀장:** 일정 관리 및 팀 커뮤니케이션 조율

**주요 구현 화면:**
- 메인 홈 화면 — 북극곰 캐릭터 + 빙하 상태 시각화
- 에코 활동 피드 — 활동 목록 조회 및 등록
- 랭킹 페이지 — 전체 사용자 랭킹 + **내 순위로 자동 스크롤**
- 마이페이지 — 활동 내역, 수집한 빙하 현황
- 온보딩 / 회원가입 화면

## 🧠 구현하며 고민하고 힘들었던 것

### 1️⃣ 랭킹 페이지 — "내 순위로 스크롤"이 생각보다 어려웠다

랭킹 목록에서 내 순위 항목으로 자동 스크롤하는 기능은 간단해 보이지만, 실제로는 까다로웠습니다.

리스트 아이템의 높이를 정확히 계산해야 했고, 스크롤 위치가 틀리면 엉뚱한 곳으로 이동했습니다.  
`scrollTo`에 전달할 `offset` 값을 아이템 인덱스와 높이로 직접 계산하고,  
`FlatList`의 `ref`를 활용해 원하는 위치로 정확히 이동하도록 여러 번 조정했습니다.

```js
// 내 순위 항목으로 스크롤
flatListRef.current.scrollToIndex({
  index: myRankIndex,
  animated: true,
  viewPosition: 0.5, // 화면 중앙으로 이동
});
```

**배운 점:** 당연해 보이는 UX 하나에도 정확한 계산과 엣지케이스 처리가 필요합니다.

---

### 2️⃣ 북극곰 캐릭터 — 직접 디자인했지만 애니메이션은 포기했다

북극곰 캐릭터는 팀이 직접 디자인했습니다.  
활동에 따라 표정이 바뀌고 움직이는 애니메이션까지 넣고 싶었지만,  
React Native에서 벡터 기반 애니메이션 캐릭터를 구현하는 건 Lottie 등 별도 도구가 필요했고,  
일정 안에 마스터하기는 어렵다고 판단했습니다.

결국 상태별로 다른 이미지를 전환하는 방식을 선택했고,  
이미지 제작에는 Gemini AI의 도움을 받았습니다.

**반성:** 기획 단계에서 기술 구현 가능성을 함께 검토했어야 했습니다.  
"넣고 싶은 기능"과 "지금 구현할 수 있는 기능"을 구분하는 눈이 필요하다는 걸 배웠습니다.

## 😔 아쉬운 점

- 시간 제약으로 팀원 작업물과의 **브랜치 병합을 완전히 마무리하지 못했습니다.**
- **댓글 등록 UI를 구현하지 못했습니다.** 에코 활동 피드에 댓글 기능이 있었지만 시간 부족으로 남겼습니다.
- 백엔드 팀원이 없어 실제 API 연동 없이 UI 중심으로 개발됐습니다.

<br>

## 📈 이 프로젝트를 마치며

EcoPolar는 제가 처음으로 **아이디어 단계부터 혼자 기획하고 디자인하고 개발까지 이끈** 프로젝트입니다.

MOAU를 하면서 배운 것들 — API 명세서를 먼저 확인해야 한다는 것, 공통 컴포넌트를 처음부터 설계해야 한다는 것, 캘린더처럼 복잡한 UI는 렌더링 단위를 먼저 설계해야 한다는 것 — 을 이번에는 조금 더 의식하면서 개발했습니다.

아쉬움도 많이 남지만, 기획부터 배포 직전까지 혼자 책임지며 완성한 경험은 어떤 프로젝트보다 많이 성장시켜준 시간이었습니다.
