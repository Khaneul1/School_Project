# 🤖 패션 이미지 분류 딥러닝 모델

> 딥러닝 프로그래밍 수업 개인 프로젝트

<br>

## 🔍 프로젝트 개요

**Fashion MNIST** 데이터셋을 활용해 옷 이미지를 입력받으면 어떤 종류의 옷인지 분류하는 딥러닝 모델을 구현한 프로젝트입니다.

티셔츠, 바지, 스웨터, 드레스, 코트, 샌들, 셔츠, 스니커즈, 가방, 앵클부츠 — 총 10가지 패션 카테고리를 분류합니다.

<br>

## 🛠 기술 스택

| 기술 | 용도 |
|---|---|
| **Python** | 전체 구현 언어 |
| **Jupyter Notebook** | 학습 환경 및 결과 시각화 |
| **TensorFlow / Keras** | 딥러닝 모델 구현 및 학습 |
| **Fashion MNIST** | 학습 데이터셋 |

<br>

## 🧠 모델 구조 개요

- CNN(합성곱 신경망) 기반 이미지 분류 모델
- 데이터 전처리 → 모델 정의 → 학습 → 평가의 파이프라인으로 구성
- 학습 과정의 loss / accuracy 시각화 포함

<br>

## 📈 이 프로젝트에서 배운 것 (그리고 힘들었던 것)

솔직히 말하면, 이 수업이 학기 내내 가장 힘들었습니다.

AI와 딥러닝에 대한 사전 지식이 전혀 없는 상태에서 시작했기 때문에,  
코드 한 줄 한 줄이 낯설고, 에러가 뜰 때마다 원인을 파악하는 것 자체가 벅찼습니다.

특히 모델 학습이 한번 돌아가기 시작하면 결과가 나올 때까지 기다려야 하는데,  
그 시간 동안 코드가 맞는지 틀린지조차 확인할 수 없어서 막막했습니다.  
한참을 기다렸다가 에러가 뜨면 다시 수정하고, 또 기다리는 과정이 반복됐습니다.

그럼에도 최종적으로 모델이 이미지를 보고 옷 종류를 맞히는 결과를 보았을 때,  
**"인공지능이 학습한다는 게 이런 것이구나"** 를 처음으로 감각적으로 이해했습니다.

이 경험을 통해 딥러닝의 구체적인 작동 방식보다,  
**모르는 영역에서 에러를 끝까지 추적하고 결과를 내는 경험** 자체가 가장 큰 배움이었습니다.
